# 虚拟宠物形象需求（1-9 年级 · 可爱活泼）

> 状态：2026-11-14 已实现独立网页程序版并补齐交互、预设及资源管理，见 [运行与验证](../avatar-demo/README.md)。正式美术资产和 App/奖励系统集成仍待确认；不将网页原型表述为正式孩子端已接入。
> 关联：孩子端答题闸门（quizgate）的「学习伙伴」候选形象；与现有 2D 狐狸（`docs/虚拟形象与按钮优化需求.md`）并行探索的 3D 方向。

## 1. 目标与受众

为 **1-9 年级小朋友** 生成一套 **可爱、活泼** 的虚拟宠物形象，作为学习伙伴/奖励载体。
风格关键词：**萌系 chibi、圆滚滚、大眼、腮红、柔和糖果色**。不是写实人物，也不是青少年二次元，是低龄向的「毛绒玩具感」小生物。

核心诉求（产品方原话）：
- 造型要 **可爱、萌**，孩子一眼喜欢。
- 要 **活泼**：有呼吸、眨眼、挥手、跳跃、跳舞等动作，不是静态贴图。
- 要能 **换装/换色**，孩子有「这是我的宠物」的归属感。
- 要能在 **手机（含微信内置浏览器、旧机型）** 上流畅打开。

## 3. 自定义维度（孩子/家长可调）

- **主色**（9 色糖果盘）与 **肚皮/副色**（8 色）。
- **配饰**：蝴蝶结 / 小围巾 / 小皇冠 / 圆眼镜 / 小花。
- **眼睛大小**（0.7–1.5）、**圆润度**（0.8–1.35）。
- **腮红** 开关。
- 年级画廊：1-9 年级各一个预设配色/配饰组合，点按即换。

## 4. 动作（活泼感来源）

- 待机：呼吸起伏 + 周期眨眼 + 轻微摆手。
- 挥手 / 跳跃 / 跳舞 / 转圈（按钮触发，单次或循环）。
- 后续可加：被点击时的开心反馈、答题正确时的庆祝（与 quizgate 判分联动）。

## 5. 技术与兼容性（硬约束，demo 已踩坑验证）

- **three.js r147 全局 UMD 版**（`vendor/three.min.js`，本地自带）。
  - 选 r147 因为它同时有：全局构建（老浏览器可用）、`ColorManagement`（颜色鲜艳）、`CapsuleGeometry`。
  - **不要用 importmap / ES module / CDN**：国内手机网络 jsdelivr 被墙、旧 Safari/微信内核不支持 importmap 会整页空白。demo 用经典 `<script>` + 全局 `THREE`。
  - 开启 `THREE.ColorManagement.legacyMode=false` + `renderer.outputEncoding=sRGBEncoding`，否则颜色发白。
- **零外部依赖**：three 本地化，手机经内网穿透/任意静态服务即可打开，无需联网加载库。
- **移动端**：宠物全屏主角、控制台收底部抽屉、图鉴/动画横滑、单指旋转双指缩放（内置轨道控制，不依赖 OrbitControls 模块）。
- 轨道控制为 demo 内置实现（拖拽/滚轮/双指 + 阻尼 + 自动旋转），见 `index.html` 的 `OrbitCam`。

## 6. 运行 demo

```bash
cd avatar-demo
python -m http.server 8090   # 或任意静态服务
# 浏览器开 http://localhost:8090
```
公网示例（frp 穿透，见 `docs` 其它穿透记录）：`http://101.35.194.117:53601/`。

## 7. 同事制作交付物（建议）

1. 基于 demo 骨架精修 9 种宠物网格/材质（或导出 glTF 替换程序化几何）。
2. 每种宠物 ≥3 套配色 + 配饰挂点（头顶/颈/眼/侧）。
3. 动作 clip：idle/wave/jump/dance/spin，含眨眼 blendshape。
4. 保持移动端性能：单宠物 draw call 控制在 ~40 内、贴图 ≤1024、阴影单光源。
5. 验收：旧 iPhone Safari / 微信内置 / 国产安卓浏览器 均能打开且 ≥30fps。

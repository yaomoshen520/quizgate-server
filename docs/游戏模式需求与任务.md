# 游戏模式需求与任务

更新：2026-11-08。首版代码已实现，自动化与本机 HTTP 验证通过；Android 11 虚拟机已安装 2048，验证倒计时、到点答题和放行，王者／和平精英及目标手机验收待完成。

## 已确认的首版流程

1. 孩子手机先展示用途说明，用户同意后同步已安装应用清单，同时启用家长规则。未同意不采集清单或上报非管控前台包名。
2. 家长在“游戏与应用”查看设备应用，系统分类及王者荣耀、和平精英包名用于自动识别；家长可标为“游戏并监管”或“非游戏”纠正。
3. 家长填写提前提醒秒数、单次延期 1—15 分钟及最多自主延期 0—2 次（次数初始为 2）。未填写两个时长不能开启游戏模式。
4. 手机检测当前前台应用，正在使用受管控游戏并接近阈值时，显示倒计时浮窗，提示剩余时间和已用／允许延期次数。
5. 孩子可以选择延期或现在答题。自主额度用完后，本轮还可向家长额外申请一次；服务端确认已提交后，等待审批期间允许继续玩。未延期、申请发送失败或被拒绝时，按原时限进入答题；答错继续解析和换题，答对放行。
6. 自主延期接在原有时限后，最后一次完整生效；家长批准的本轮一次额外时长也必须给满。已超过原时限才批准时，从收到批准起计满；不开放第四次申请。细节见[家长审批延期](家长审批延期.md)。
7. 同一轮连续使用跨游戏共用次数，答对后开始下一轮并恢复次数。家长修改规则从下一轮生效，保留当前周期已给出的时间。

本版按最终有效时限执行，可打断当前对局；已提交的申请按用户选择允许继续等待，不另设审批超时。不包含对局结束、结算页或游戏画面识别。普通安装在无障碍／覆盖能力被关闭时不能保证强制弹窗，仍需记录失败及告警。

## 首版执行与恢复口径

- 游戏周期离开应用或熄屏时暂停，不清空累计时长和延期次数，返回继续；普通非游戏周期沿用离开宽限和熄屏逻辑。
- 保存当前周期规则版本、累计时长、已用次数及已增加时长；切换游戏、进程重启、设备重启或修改系统时间不补发次数。不把进程停摆和熄屏时段计为游戏时长。
- 延期先写入持久状态再更新界面；重复点击不得额外增加次数，写盘失败不得给出额外时间。
- 断网按有效缓存执行，联网后重传记录；家长网页展示设备上报时间和实际执行版本，不将缓存状态显示为实时画面。
- 应用清单约每 5 分钟同步，前台包名和游戏状态随心跳上报。分类覆盖不被下一次应用扫描抹掉。
- 游戏模式关闭前不启用未知时长默认值；开启时监管自动识别或家长标为游戏的应用，总闸门关闭时不执行。
- 每日总额度仍未执行，额度耗尽后如何处理继续记录在主文档 D1，不因游戏延期默认放宽。

## 后续验收清单

- 安装新版 APK、绑定设备、同意应用清单、开启无障碍及答题覆盖能力后，家长页面能看到本机实际应用；拒绝时不上传清单。
- 王者荣耀、和平精英前台倒计时可见，尽量少遮挡操作；浮窗不抢走游戏焦点，横竖屏后不重复显示。
- 0、1、2 次自主上限分别生效；每次最多 15 分钟；用尽后仅提供本轮一次家长申请，等待、批准与拒绝符合[审批规则](家长审批延期.md)。
- 切换游戏、桌面、系统设置、熄屏、重启及断网符合上述口径，答对后恢复次数；无法显示时记录实际失败。
- 家长中途修改规则只影响下一轮，网页能够区分已保存版本与手机本轮执行版本。
- 厂商游戏模式、权限撤销、后台清理及长时间运行在实际目标手机专项验证。

## Android 可见性与分发边界

应用列表同意、应用可见性、无障碍前台检测和覆盖显示是不同能力。Android 11 及以上目标版本默认过滤包查询，不能把一个普通运行时权限弹窗当成能读取任意完整清单。

首版使用 QUERY_ALL_PACKAGES 支持核心家长管控清单，采集范围以设备当前个人资料中系统允许查询的应用为准；工作资料等不保证可见。当前交付为 Debug APK，未代表获得应用商店对该权限的审批。系统 CATEGORY_GAME 只是分类依据之一，未知分类需要家长确认。

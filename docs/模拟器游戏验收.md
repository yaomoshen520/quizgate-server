# 模拟器游戏验收

本文记录 0.3.1 首次游戏浮窗验收；后续 0.4 在线家长审批和时间配置验收见[家长审批延期](家长审批延期.md)。

本轮在已有 Android 11（API 30）、720 × 1280 虚拟机中安装真正可玩的 2048，未新装系统镜像或 Android Studio。测试虚拟机是独立的 `quizgate-local`，不是家庭真机。

- 游戏：[2048 Open Fun Game 官方发布 1.16.2](https://github.com/andstatus/game2048/releases/tag/1.16.2-release)，包名 `org.andstatus.game2048`、versionCode 47，安装包 1,354,547 字节。
- 从官方 GitHub 发布资产下载，SHA-256 与官方资产摘要一致：`12191f38ae70c1113bb4bec66a1fa4b2cf0d6f15b39371a7446ce2f6f181c4e6`；v2 签名校验通过。
- 孩子端修复版本：`0.3.1-game-overlay`、versionCode 4；保留日志与性能功能。
- 本机演示规则：游戏连续使用 60 秒，提前 20 秒提醒，每次延期 60 秒、最多 2 次；不操作则到点答题。正式规则仍允许家长在每次不超过 15 分钟、最多 2 次内选择。

## 发现并修复的问题

原实现直接把无障碍 `TYPE_WINDOW_STATE_CHANGED` 事件的包名当作前台应用。游戏提醒浮窗属于 Quizgate，自身浮窗出现时会产生 Quizgate 的窗口事件，导致计时器误判离开游戏并立即收起提醒；下次 tick 又显示，形成反复显示／收起，游戏计时也会暂停。

新实现开启交互窗口元数据访问，优先读取具有输入焦点的应用窗口的根节点包名。非焦点的提醒窗口不会替换其下游戏的前台身份；真正切到其他应用仍能暂停。只读取根节点包名，不遍历控件文字、截图或游戏聊天。

## 已验证与边界

- 2048 安装及正常打开，能够滑动方块。
- 游戏中倒计时浮窗稳定显示，原先反复显示／收起的问题在该虚拟机不再出现。
- 未选择延期，到点显示答题浮层；答对后显示成功并放行。
- 点击“延长 1 分钟”，持久状态由 0/2 更新为 1/2，已增加时长为 60 秒，浮窗收起并继续游戏。两次耗尽和最后一次延期完整生效已有单元测试，本轮未把它们表述为已完整人工跑完。
- 修复后的 APK 构建、签名校验及 76 项 Android 测试通过。

延期按钮的实测结果和当前演示状态见工作区 `outputs/虚拟机演示状态.json`；截图保存在 `outputs/quizgate-2048-*.png`。本文件不把模拟器表现当成王者荣耀、和平精英或厂商真机验收，横屏、长时间运行、权限撤销、重启保留次数仍需专项验证。

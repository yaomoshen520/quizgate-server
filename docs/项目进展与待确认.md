# 项目进展与待确认

更新：2026-11-09。本文记录三个仓库的当前实现、验收范围及待用户确认的产品规则。
“拟议方案”不代表用户已批准；待确认项保持现状，不据此自动增加管控策略。

关联仓库：[服务端](https://github.com/yaomoshen520/quizgate-server)、[家长后台](https://github.com/yaomoshen520/quizgate-console)、[孩子端](https://github.com/yaomoshen520/quizgate-android)。

## 已完成及验证范围

- 孩子端联网取题、服务端判分、答错看解析后换同知识点题，答对后放行。
- 设备未登记或绑定、断网、题库为空、响应异常时使用本地题；远端提交失败会换本地新题，仍需答对，不自动放行。
- 娱乐用量、答题结果及抢屏失败持久化；稳定事件 ID 重传去重，收到确认后只清除该批记录。
- 服务端拒绝未绑定设备取题、判分和用量确认，防止共享孩子归属或绑定前丢失待补报记录。
- 前台包名探测、浮窗关闭后恢复计时、熄屏边界、本地混合运算答案、启用跟随时重新获取同版本阈值均已修复。
- 家长后台规则说明、出题统计口径、失联文案、题库核对反馈及窄屏表格展示已修正。
- 构建环境使用便携 JDK、必要 SDK 组件及可选镜像，未新装 Android Studio、NDK 或系统镜像；模拟器复用已有镜像并使用独立 AVD 数据。

游戏模式开发前的验证：服务端 64 项测试、Android 57 项测试通过；前端协议生成、类型检查及生产构建通过。
完成真实 HTTP 接口检查、实际 Kotlin 客户端联调及 Android 11 模拟器联调，包括联网答题、离线换题、恢复补报和无障碍关闭告警。
家长后台已验证桌面及 390 × 844 窄屏。模拟器与测试样本的结果不代表所有真机或真实家庭的使用结果。

现场演示使用隔离测试账号和 10 秒阈值。演示私有题库仅有一道题，换题可能仍抽到原题，需补足同知识点题量。
仓库不收录测试数据库、令牌、密码、截图录像、APK/JAR 产物、SDK 或构建缓存。

## 待用户确认的产品规则

| 编号 | 需要决定的问题 | 当前实现／可选方向 |
| --- | --- | --- |
| D1 | 每日额度与其余规则 | 每日额度用完后停止娱乐，还是答题后仍能继续？当前每日限额未执行；新版本开关、清单和宽限已接入家长规则。 |
| D2 | 设备管理方式 | 优先支持现有手机直接安装，还是接受新机／恢复出厂并采用 Device Owner 管理？此选择影响可提供的防关闭、防卸载能力；具体机型仍需验证。 |
| D3 | 拍照题审核 | 所有拍照题均由家长确认，还是允许服务端计算核验通过的算术题自动可用？当前代码允许自动核验通过的题可用，未改成一律人工确认。 |
| D4 | 失联告警 | 继续固定约 3 分钟无心跳告警，还是增加夜间免打扰、可配置时长或其他策略？失联只说明没收到心跳，不能确定是卸载、关机还是断网。 |
| D5 | 内置题库入口 | 是否为家长提供内置题库的显式只读查看、说明或筛选入口？当前未新增该流程。 |

## 游戏模式：首版实现，待实际游戏验收

此前用户要求先暂停游戏模式。2026-11-07 最新要求恢复需求整理，改为：取得授权后获取已安装应用，识别当前前台游戏，接近时限先倒计时提醒；孩子可在家长设置的次数内延期，最终到点强制答题。

本版不依赖识别一局结束；延期用尽后的最终时限允许中断当前对局。王者荣耀、和平精英列入首批验收应用。

完整需求、G0—G10 开发任务及后续验收清单见[游戏模式需求与任务](游戏模式需求与任务.md)。
已实现上述首版流程。此前 Android 66 项测试、服务端 66 项测试、前端构建和 19 次真实 HTTP 检查通过。后续日志与浮窗修复版本通过 Android 76 项测试。模拟器曾因当前执行环境的硬件加速探测和软件启动失败无法联调；用户从本机启动后已连接成功，并在 2048 中完成提醒、到期答题和放行验证。王者／和平精英及目标手机待验收，具体范围见[模拟器游戏验收](模拟器游戏验收.md)。

## 后续验收条件

- 规则执行：家长保存后，手机执行的版本和实际行为一致，离线／重启边界有明确口径。
- 孩子端：生产默认值及家长验证确定后，普通孩子操作不能直接进入调试配置改变管控。
- 拍照：使用真实模型和照片，验证识别、答案核验、家长审核及孩子取题完整链路。
- 真机：使用实际目标手机测试长时间运行、清后台、重启和权限关闭，记录可复现的边界。
- 发布：使用正式服务与发布包验证安装、绑定、网络、升级和数据保留；不混入本轮测试账号与数据。

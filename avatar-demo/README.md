# 萌宠星球

按《虚拟宠物形象需求》实现的独立网页原型。经典脚本、本地 three.js r147，无 CDN、模块加载器、构建步骤或新增运行库；整个目录可部署到静态服务。未接入孩子档案、闸门或积分。

## 运行

在有 Python 的电脑上，从本目录运行：

```sh
python -m http.server 8090 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8090/`。手机访问需自行使用已允许的局域网静态服务地址；本轮不新建公网穿透或发布服务。

## 功能

- 九种程序化宠物；每种原色/糖果/花园三套配色灵感，九主色、八副色和五种配饰可继续混搭。
- 眼睛 0.7—1.5、圆润度 0.8—1.35、腮红开关；狐狸白尖尾、猫弯长尾、熊猫眼圈、火龙翅膀等物种差异。
- 1—9 年级造型按钮只是外观灵感，不修改真实年级、规则、周期或延期次数。
- 待机呼吸/眨眼/轻摆手；挥手、跳跃、跳舞、转圈，支持循环及单次结束回待机。切换后还原脚部及旋转，重复选择正在执行的状态不会重新计时。
- 单指拖拽、滚轮和双指缩放；手机竖/横屏底部抽屉，宠物和年级画廊横向滑动。抽屉可键盘关闭，按钮有标签和焦点提示。
- 点击“保存本机造型”后仅写当前浏览器 `localStorage` 的 `quizgate.pet-demo.v1`，刷新恢复。不含孩子标识/令牌；存储失败不阻断换装。重置只改当前预览，再保存才覆盖原造型。
- 截图按用户点击生成 PNG；不上传。截图与已有浏览器下载设置有关，Safari/微信的实际下载行为待真机确认。
- 不支持 WebGL 或渲染初始化失败时显示重试提示；WebGL 上下文丢失时停帧，恢复后重新布局。

## 性能和动态效果

隐藏页面取消动画帧并停止动画计时；回来后不补算停留时间。跟随系统 `prefers-reduced-motion`：减少动态时停自动动画和自动旋转，保留换装及手动查看，并显示原因。没有增加常驻服务或唤醒锁。

静态部件按共享材质合并，身体、手脚和眼睛保留独立动画节点；模型重建时对共享 geometry/material 去重释放。手机关闭实时阴影、像素比最多 1.5；桌面单阴影光源，阴影图 1024。`PetApp.inspect()` 可在开发者控制台查看当前网格数、渲染调用和资源计数，不上传这些数据，不在普通界面增加技术开关。

## 检查

Node.js 18+，无需 npm install：

```sh
node --test tests/pets.test.cjs
```

2026-11-14：7 项测试通过，包括实际 three.js 构建的 **162 种组合**、非法本机配置、单次/重复动作、脚部复位及 30 次重建的去重释放。组合中最多 **21 个宠物 Mesh / 15,096 三角形**。这不是包含环境/阴影的 GPU draw call 数，也不证明目标设备达到 30fps。

本机浏览器验证了九种宠物切换、配饰、9 年级预设、抽屉、保存和刷新恢复（含腮红关闭状态），桌面 1280×720、手机视口 390×844 及横屏 844×390 可见。当前测试浏览器启用了系统减少动态效果，已验证相应提示和禁用行为；正常动态的状态逻辑由 Node 测试覆盖，真实旧 iPhone、微信/国产浏览器、正常模式连续动画、上下文恢复和长期 GPU 内存/帧率仍需设备验收。

## 文件和后续

最终美术、是否交付 glTF/动画 clip/blendshape、正式 App 的嵌入方式、跨端同步、积分规则等不在本轮自行决定，见 [需求与待确认](../docs/虚拟宠物形象需求.md)。当前眨眼为程序化缩放，未交付独立的 blendshape 或 glTF 资产。
